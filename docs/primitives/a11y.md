# Announcer

The `Announcer` speaks text for the elements on the focus path. Each time
focus changes, it collects text from the elements that are new on the path and
passes it to a speech engine.

Accessibility as a framework feature, with semantics on every target, is in
progress in an open pull request and is not on `main`. This page describes the
`Announcer` primitive that exists today. It speaks through the browser's
`speechSynthesis`, or writes ARIA labels when `Announcer.aria` is `true`, so it
works only on hosts that have those browser APIs.

## Usage

```tsx
import { useAnnouncer } from '@solid-multiplatform/platform/primitives';

export const App = () => {
  const announcer = useAnnouncer();
  announcer.enabled = true;

  return (
    <view announce="Home" announceContext="Press LEFT or RIGHT to browse">
      <view autofocus announce={['Despicable Me', '2010', 'Rated PG']} />
    </view>
  );
};
```

Call `useAnnouncer()` once, inside your app. It sets up the timers and follows
`focusPath`. Later calls return the same `Announcer` object.

## What is announced

For each element that is new on the focus path, from the root to the focused
element, the announcer reads `announce`, or else `title`. It then walks back
from the focused element to the root and reads `announceContext`.

After a period without focus changes (five minutes by default), the next
change announces the full path again.

## SpeechType

`announce`, `title` and `announceContext` take a `SpeechType`:

```ts
type CoreSpeechType =
  | string
  | (() => SpeechType)
  | SpeechType[]
  | SpeechSynthesisUtterance;
type SpeechType = CoreSpeechType | Promise<CoreSpeechType>;
```

A string of the form `PAUSE-2.5` pauses for that many seconds:

```ts
const announce = ['Loading', 'PAUSE-2.5', 'Done'];
```

## API

Properties:

- `enabled` (`boolean`, default `true`): turns announcing on or off.
- `debug` (`boolean`, default `false`): print what is announced with
  `console.table`.
- `lang` (`string`, default `'en-US'`): language passed to the speech engine.
- `voice` (`string`): voice name passed to the speech engine.
- `aria` (`boolean`, default `false`): write ARIA labels for a screen reader
  instead of calling `speechSynthesis`.

Methods:

- `speak(text, options)`: announce `text` now. `options.append` adds it to
  what is being spoken. `options.notification` speaks it and then announces
  the focus path again.
- `cancel()`: stop speaking.
- `refresh(depth)`: forget the last announced path from `depth` and announce
  again.
- `clearPrevFocus(depth)`: forget the last announced path from `depth`.
- `setupTimers({ focusDebounce, focusChangeTimeout })`: `focusDebounce` is the
  wait after the last focus change before announcing (default `400` ms).
  `focusChangeTimeout` is the idle time after which the full path is announced
  again. `useAnnouncer(options)` passes the same options on its first call.

## Timers

The announcer's timers are debounces that start on a focus change. Nothing is
scheduled if you never call `useAnnouncer()`.
