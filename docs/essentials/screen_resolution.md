# Screen resolution

You author the scene in one fixed logical size and let the renderer scale it to
the screen. 1920 by 1080 is the usual choice for TV.

On the WebGL backend three renderer settings control this:

- `appWidth`, `appHeight`: the logical size you author in.
- `deviceLogicalPixelRatio`: scales your logical coordinates to the device's
  logical pixels.
- `devicePhysicalPixelRatio`: how many physical pixels to draw per device
  logical pixel.

In a browser, derive the ratio from the window height:

```tsx
import { startApp } from '@solid-multiplatform/platform/host';
import { webHost } from '@solid-multiplatform/platform/host/web';

startApp(webHost(), () => <text>Hello World</text>, {
  renderer: {
    appWidth: 1920,
    appHeight: 1080,
    // 720p = 0.666667, 1080p = 1, 1440p = 1.333333, 2160p = 2
    deviceLogicalPixelRatio: window.innerHeight / 1080,
  },
});
```

The scene keeps its 1920 by 1080 coordinates. Only the scale changes.

If your app must adapt to the window instead of scaling, read the live size
from `viewport()` in `@solid-multiplatform/platform/viewport`, as the app
generated by `solid-platform init` does:

```tsx
import { viewport } from '@solid-multiplatform/platform/viewport';

<view width={viewport().width} height={viewport().height} />;
```
