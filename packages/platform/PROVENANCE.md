# Source records

- Framework, universal JSX binding and primitives descend from [vynxc/solid at 9ab7982](https://github.com/vynxc/solid/tree/9ab79829aff3855cfccfbd7c9e2f90bf107d7559). The repository retains the fork’s Git history, Apache license, notices and compatibility tests.
- The renderer lives in this repository under `packages/renderer`. Its history was merged from [solid-multiplatform/renderer at 8772019](https://github.com/solid-multiplatform/renderer/tree/8772019c4a30db1b19e2d1aa3efd22c4abc8068f); its own source records cover the published renderer inputs, the Canvas and WebGL backends, Roku SceneGraph and the upstream licenses.
- The SceneGraph host, worker components and extension references are derived from the [Roku directory](https://github.com/viptv-org/tv-web/tree/9924e7ce6961f78b193f3e5d62a31831ae6bff8b/roku), revision 9924e7c. The import accessed only the two requested directories, roku and patches. Each downloaded file was checked against its Git blob ID. Host files retain the directory license, with font notices alongside their assets.
- Android integration comes from the local `solid-demo-app-android-native` checkout at 6953d6e2a60254d2472f11f815ce489bd772f899. tvOS boot and simulator project settings come from the local `solid-demo-app` checkout at 758ae76eb9baa8af7d7774522977a54d8e842bcc. The reusable NativeScript platform, remote, lifecycle and shim code comes from the [0.1.3 package](https://registry.npmjs.org/@solidtv/nativescript/-/nativescript-0.1.3.tgz), with its Apache license in hosts/nativescript. The Android fixture builds with the published beta.6 native Canvas library. The original project's optional multisampling patch is recorded in hosts/android-tv/patches.
- [Community Solid Primitives](https://github.com/solidjs-community/solid-primitives/tree/f0c19092dba31c85e9328cfd000591c6fb8d1884) is a pinned, separately cloned development reference. The platform retains the community package dependencies used by its extracted UI primitives.
- The code derived from `viptv-org/tv-web` (its `roku` and `patches` directories) is contributed to this project by its copyright holder under this project's licenses (Apache-2.0 for the platform and renderer; MIT is retained where the Roku directory carried it). This was confirmed by the owner on 2026-11-18.
