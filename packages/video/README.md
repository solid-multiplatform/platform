# @solid-multiplatform/video

Optional playback adapters for [Solid Multiplatform](https://github.com/solid-multiplatform/platform). The renderer and platform packages do not depend on it and carry no media decoder; import it from a player screen or a lazy route.

The package root exports the browser player (VIPTV video 0.4.0, over `hls.js` and `mediabunny`; see [PROVENANCE.md](PROVENANCE.md)). The other adapters are subpaths:

- `/android`: `createAndroidPlayer`, on Media3. The app's Gradle build needs the ExoPlayer, UI, HLS and DASH modules; a project generated by the CLI gets them when the video package is installed.
- `/apple`: `createApplePlayer`, on AVPlayer.
- `/roku`: `createRokuPlayer`, on a SceneGraph `Video` node owned by the host as a layer beneath the app (the scene's transparent regions composite over it). `hosts/roku` adds a `mediaSession` port and a `mediaCapabilities` service; `createRokuVideoApi` hands the port to app code.
- `/native`: `PlaybackSessionController`, the headless session controller without browser codecs, for coordinating the native players.
- `/swift`: the Swift source the CLI copies into Apple builds.
- `/desktop`: `createDesktopPlayer`, on mpv over IPC. It was written for a Node-based desktop host; it does not run in the current Rust + Hermes runtime and is untested.

Install the package into a generated app with the CLI:

```sh
corepack pnpm platform add video <path-to-solid-multiplatform-video-<version>.tgz>
```

## Status

Honest, per adapter:

- **iOS and tvOS**: tested in the Apple simulators (`packages/platform/tests/cli/apple-smoke.sh`, CI job `apple`): a clip opens, plays, pauses and seeks. Not tested on a physical device.
- **Roku**: verified by a recorded run on a physical TV (`packages/platform/tests/roku-device/run-video.mjs`): open, play, pause, seek, end, error mapping, teardown with no pending work.
- **Android and Android TV**: CI checks that the built APK contains the Media3 player and its layout; playback itself is checked only when the smoke script is run with an emulator.
- **Web and desktop**: preview; no automated playback test.

Nothing is checked on a physical Apple device, and DRM and track selection need qualification per device. The per-feature status is in the [feature matrix](../../docs/features.md).
