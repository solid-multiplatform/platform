# Solid Multiplatform video

The optional media package exports the complete public API of [VIPTV video 0.4.0](https://github.com/viptv-org/video/tree/1e879410c8df550d0d8ad542c40bbc8d67e7c041). Import it from a player screen or a lazy route. The base UI runtime has no dependency on media codecs or Tauri. Browser, Vizio, AVPlay and Tauri retain the upstream capability and delivery rules. A browser feature report describes the current engine; the TV support matrix records device qualification separately.

Native hosts can import `createAndroidPlayer`, `createApplePlayer`, `createRokuPlayer`, or `createDesktopPlayer` from the respective subpath. These are preview adapters. Android uses Media3 and needs ExoPlayer, the UI module, and the HLS/DASH modules in the app's Gradle dependencies. Apple uses AVPlayerLayer. Roku accepts an explicit SceneGraph parent. Desktop uses MPV IPC attached to an SDL X11/Win32 native window handle. Use `PlaybackSessionController` from `./native` when coordinating these players; that entry contains the pinned headless session controller without browser codecs. Direct protected headers are rejected by these native adapters. Read each engine's capability report; DRM and track support need independent qualification. Native decoder readiness, picture placement, and physical playback are distinct checks.
