# @solid-multiplatform/video

Optional playback adapters for [Solid Multiplatform](https://github.com/solid-multiplatform/platform). The renderer and platform packages do not depend on it and carry no media decoder. Import it from a player screen or a lazy route.

The package root exports the public API of [VIPTV video 0.4.0](https://github.com/viptv-org/video/tree/1e879410c8df550d0d8ad542c40bbc8d67e7c041) for browsers. See [PROVENANCE.md](PROVENANCE.md).

## Native adapters

- `/android`: `createAndroidPlayer`, on Media3. The app's Gradle dependencies need ExoPlayer, the UI module and the HLS and DASH modules; a project generated by the CLI gets the HLS and DASH modules when the video package is installed.
- `/apple`: `createApplePlayer`, on AVPlayer.
- `/roku`: `createRokuPlayer`, on a SceneGraph `Video` node owned by the host as a layer beneath the app (the scene's transparent regions composite over it). `hosts/roku` adds a `mediaSession` port and a `mediaCapabilities` service; `createRokuVideoApi` hands the port to app code.
- `/desktop`: `createDesktopPlayer`, on mpv over IPC. It belongs to the Node-based desktop host that is being replaced.
- `/native`: `PlaybackSessionController`, the headless session controller without browser codecs, for coordinating the native players.
- `/swift`: the Swift source the CLI copies into Apple builds.

Install the package into a generated app with the CLI:

```sh
corepack pnpm platform add video /path/to/solid-multiplatform-video-<version>.tgz
```

## Status

These adapters are preview. What CI checks:

- iOS and tvOS simulators: `packages/platform/tests/cli/apple-smoke.sh` opens a clip, plays until time advances, pauses and seeks (CI job `apple`).
- Android TV: `packages/platform/tests/cli/android-smoke.sh` asserts that the player and its layout are in the built APK (CI job `android`). Playback is checked only when you run the script with an emulator.
- Roku: `packages/platform/tests/roku-device/run-video.mjs` opens a clip paused, plays, pauses, seeks with the remote, reaches the end, maps an unreachable URL's firmware error and checks teardown leaves no timer, on the TV named by `ROKU_DEV_IP`.
- `npm test` in this directory runs the package's own Node tests.

Nothing is checked on a physical device. DRM and track selection need qualification per device. The per-target status is in the [feature matrix](../../docs/features.md).
