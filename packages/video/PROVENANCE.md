The upstream ESM distribution, declarations and maps are built verbatim from viptv-org/video revision 1e879410c8df550d0d8ad542c40bbc8d67e7c041 using its npm lockfile. All 220 upstream tests passed. The files in core, except entry.ts, are the corresponding pinned session, error, policy and authorization sources. Build core.mjs with esbuild core/entry.ts --bundle --format=esm --outfile=core.mjs. They allow native apps to import the same session coordinator without loading a browser playback engine. Both upstream licenses accompany this package.

The Android content layout derives from the Apache-2.0 [Media3 1.4.0 PlayerView layout](https://github.com/androidx/media/blob/1.4.0/libraries/ui/src/main/res/layout/exo_player_view.xml). It retains the native video, subtitle, artwork, accessibility and overlay elements and omits the placeholder that creates the unused Media3 transport controller.
